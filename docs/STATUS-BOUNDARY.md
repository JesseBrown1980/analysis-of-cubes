# Status boundary

Use these labels without collapsing them:

- `VERIFIED_LOCAL`: bytes exist on the current seat and pass the recorded hash.
- `REPORTED_REMOTE`: another seat reports the result; current seat does not possess the bytes.
- `MEASURED_REPO`: committed code or artifacts provide a reproducible local measurement.
- `DESIGN_LINEAGE`: architecture or mathematical construction without a current execution result.
- `HYPOTHESIS`: falsifiable interpretation awaiting measurement.
- `UNRESOLVED`: official case status; it does not mean anomalous technology was established.
- `HELD`: an admission condition is missing.

Provider execution and scientific evidence have separate ledgers.
